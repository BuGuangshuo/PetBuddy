# 更新日志弹窗 - 快速指南

## 如何添加新版本的更新日志

### 1. 编辑 USER_CHANGELOG.md

在文件顶部添加新版本的内容：

```markdown
# 🐶 PetBuddy 更新日志

嘿！这里记录了 PetBuddy 的每次更新，看看你的桌面小伙伴又学会了什么新技能～

---

## 🎉 v0.3.0 - 2026年5月15日

### ✨ 新功能

**🎨 新的主题系统**
- 支持自定义主题颜色
- 新增夜间模式

### 🔧 优化改进

**性能提升**
- 启动速度提升 50%
- 内存占用减少 30%

### 🐛 修复问题

- 修复了某个 bug
- 解决了另一个问题

---

## 🎉 v0.2.0 - 2026年5月10日
...（旧版本内容）
```

### 2. 更新 package.json 版本号

```json
{
  "version": "0.3.0"
}
```

### 3. 添加装饰 GIF（可选）

将新的 GIF 文件放到 `pet_assets/ChangeLogModal/` 目录：
- 文件名任意（会自动选择第一个 .gif 文件）
- 建议尺寸：200px 宽度左右
- 格式：GIF 动画

### 4. 构建和发布

```bash
npm run build
npm run package
```

## 弹窗显示规则

✅ **会显示弹窗的情况**：
- 用户首次打开设置面板（`lastViewedChangelogVersion` 为 null）
- 应用版本更新后首次打开设置面板

❌ **不会显示弹窗的情况**：
- 用户已经查看过当前版本的更新日志
- 版本号没有变化

## Markdown 格式要求

### 版本标题
```markdown
## 🎉 v0.3.0 - 2026年5月15日
```
- 必须以 `## 🎉 v` 开头
- 版本号格式：`数字.数字.数字`
- 日期可选

### 章节标题
```markdown
### ✨ 新功能
### 🔧 优化改进
### 🐛 修复问题
```
- 必须以 `### ` 开头（三个 # + 空格）
- 可以使用 emoji

### 列表项
```markdown
- 普通列表项
**粗体标题**
- 子项 1
- 子项 2
```
- 使用 `-` 或 `**` 标记
- 支持粗体标题

## 常见问题

### Q: 弹窗不显示？
A: 检查：
1. 版本号是否更新
2. `USER_CHANGELOG.md` 中是否有对应版本的内容
3. 用户是否已经查看过（检查 `lastViewedChangelogVersion`）

### Q: 装饰 GIF 不显示？
A: 检查：
1. GIF 文件是否在 `pet_assets/ChangeLogModal/` 目录
2. 文件扩展名是否为 `.gif`
3. 文件是否损坏

### Q: 格式显示不正确？
A: 检查：
1. 章节标题是否使用 `### ` 开头
2. 列表项是否使用 `-` 开头
3. 是否有多余的空行或格式错误

### Q: 如何测试弹窗？
A: 
1. 删除本地存储中的 `lastViewedChangelogVersion`
2. 或者修改 `package.json` 中的版本号
3. 重新打开设置面板

## 样式自定义

如果需要修改弹窗样式，编辑 `src/renderer/src/styles.css` 中的以下类：

- `.changelog-overlay` - 遮罩层
- `.changelog-modal` - 模态框
- `.changelog-header` - 标题栏
- `.changelog-section` - 章节卡片
- `.changelog-section-title` - 章节标题
- `.changelog-section-items` - 列表项
